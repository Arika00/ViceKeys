# ViceKey

ViceKey is a Windows-focused keyboard-and-mouse input layer for Chiaki-ng / PlayStation Remote Play.

The current repository snapshot contains the previous experimental patcher and the source files used for its architecture audit. It is a starting point for continued development, not a completed in-game overlay.

See [AUDIT.md](AUDIT.md) for the current findings, known blockers, and implementation plan.

No build is claimed by this snapshot. A complete Chiaki-ng checkout and the missing build script/toolchain setup are required before a reproducible Windows build can be verified.

## Privacy

Do not commit personal paths, credentials, access tokens, local configuration, private logs, or machine-specific files. Keep this repository limited to project source, build instructions, and non-personal test material.
